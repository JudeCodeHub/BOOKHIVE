# Fonts for PDFs

Noto Sans, Noto Sans Sinhala and Noto Sans Tamil (regular and bold), embedded in report PDFs so
English, Sinhala and Tamil text all show (checklist step 366). From
https://github.com/notofonts/notofonts.github.io (hinted TTF), under the SIL Open Font License 1.1
(`OFL.txt`), which allows bundling them with software.
